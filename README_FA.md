# شکارچی کد دیجی‌کالا — نسخه ۴

## امکانات
- باز کردن صفحه عمومی مسابقه در WebView
- پیمایش صفحه برای بارگذاری تصاویر lazy-loaded
- جمع‌آوری تصاویر قابل‌مشاهده در DOM (حداکثر ۸۰ تصویر جدید در هر صفحه)
- OCR با Google ML Kit
- حذف URLهای تکراری در اجرای فعلی
- تشخیص الگوی احتمالی DK به همراه ۳ تا ۸ نویسه
- اسکن حداکثر ۵ صفحه با لینک «بعدی» قابل‌شناسایی
- ذخیره تاریخچه کدهای احتمالی روی گوشی
- کپی دستی کد پیدا‌شده

## ساخت APK
1. Android Studio را نصب و اجرا کن.
2. فایل ZIP را Extract کن.
3. پوشه DK_Hunter_Android_Project_v4 را در Android Studio باز کن.
4. صبر کن Gradle Sync کامل شود.
5. از منوی Build گزینه Build APK(s) را انتخاب کن.
6. فایل APK معمولاً در app/build/outputs/apk/debug/ ساخته می‌شود.

## محدودیت‌ها
- این فایل سورس پروژه است، نه APK کامپایل‌شده و تست‌شده.
- فقط تصاویر عمومی بارگذاری‌شده در صفحه قابل‌بررسی هستند.
- اسکن چندصفحه‌ای به وجود لینک «بعدی» قابل‌شناسایی وابسته است.
- الگوی DK یک حدس است و ممکن است قالب کد واقعی متفاوت باشد.
- تصاویر دارای محدودیت دسترسی ممکن است خوانده نشوند.
- در صورت دریافت HTTP 403 یا 429 اسکن متوقف می‌شود.
- CAPTCHA، ورود و کنترل‌های ضدربات دور زده نمی‌شوند.
- هیچ کدی خودکار ثبت یا ارسال نمی‌شود.


## ساخت خودکار APK در GitHub
این پروژه فایل Workflow آماده دارد:
`.github/workflows/android-apk.yml`

پس از آپلود همه فایل‌های پروژه به شاخه `main`:
1. وارد زبانه **Actions** مخزن شو.
2. گردش‌کار **Build Android APK** را انتخاب کن.
3. روی **Run workflow** و سپس دکمه سبز **Run workflow** بزن؛ یا با هر push به `main` به‌صورت خودکار اجرا می‌شود.
4. پس از اتمام موفق، وارد اجرای (run) مربوطه شو.
5. در بخش **Artifacts** فایل `DK-Hunter-debug-APK` را دانلود و ZIP آن را استخراج کن.
6. فایل `app-debug.apk` داخل آن قرار دارد.

این APK نسخه debug برای آزمایش است، نه نسخه release امضاشده برای انتشار عمومی.
